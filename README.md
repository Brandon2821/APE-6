APE 06 - Arreglos y Listas
Descripción

Este proyecto corresponde al desarrollo de la Guía APE 06 de la asignatura Algoritmos y Lógica de Programación de la Universidad Técnica de Ambato. Se implementaron ejercicios prácticos utilizando estructuras de datos como ArrayList, LinkedList y arreglos en Java.

Objetivo General

Desarrollar programas en Java utilizando arreglos, ArrayList y LinkedList para almacenar, gestionar y manipular datos de manera eficiente, aplicando los fundamentos de la lógica de programación y las estructuras de datos dinámicas.

Ejercicios Desarrollados
ArrayList con 5 nombres de estudiantes.
ArrayList con 6 notas.
Registro y búsqueda de productos.
Menú CRUD usando ArrayList.
Registro de nombres y notas.
Sistema de inventario.
Comparación entre arreglos y ArrayList.
Comparación de inserción de datos.
Manipulación de turnos con LinkedList.
Simulación de una fila de atención.

Resultados Obtenidos
